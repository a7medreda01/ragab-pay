النوع: عرض فني ومالي لبرمجة وتطوير المنظومة

يقدم هذا العرض دراسة فنية وهندسية شاملة لبرمجة وتطوير منصة Ragab Pay الفندقية المتكاملة؛ وتشمل خوادم سحابية وقواعد بيانات مركزية مؤمنة، متصلة بـ 3 لوحات ويب متقدمة (الإدارة، المالك، والنزيل شبيه بـ Airbnb)، وتطبيق جوال أصيل لـ iOS و Android مع رفعهما للمتاجر الرسمية، ونموذج ذكاء اصطناعي مخصص (AI Model) كمرحلة مستقلة لتعزيز كفاءة الحجز والتسعير.

أولاً: تفاصيل لوحات التحكم والواجهات البرمجية (Core Portals & Scope)
1. لوحة تحكم الإدارة العامة (Super Admin)
التحكم والسيادة المركزية
  • التحكم في العملاء والملاك وتوثيقهم: توثيق الهويات الرسمية (KYC) وتوثيق العقارات والأماكن بالصور والوثائق قبل التفعيل.
  • تسعير وعمولات مخصصة لكل مالك: تحديد نسبة عمولة إدارة خاصة ومتغيرة لكل مالك/وحدة وليست نسبة ثابتة.
  • مراجعة وقبول الوحدات: تدقيق بيانات ومواصفات وأسعار الشاليهات وقبولها أو إرجاعها للمالك بملاحظات.
  • نظام إنذارات وإدارة التزام الملاك: مراقبة وإلزام الملاك بالتحديث اللحظي لحالة الوحدات (مثل الحجز الخارجي لمنع Overbooking).
  • إدارة المدفوعات ومستحقات الملاك: كشوف حساب دقيقة، جدولة التحويلات البنكية واحتساب عمولة المنصة تلقائياً.
  • إدارة الإلغاءات واسترجاع المبالغ: تطبيق سياسات الإلغاء (مرنة، معتدلة، صارمة) ورد المبالغ المستحقة إلكترونياً.
  • لوحة تحليلات رقمية متقدمة (Power BI Style): رسوم بيانية ومؤشرات حية للإشغال، الإيرادات، ومعدلات الأداء.
2. بوابة المالك للوحدات والأرباح (Owner Portal)
إدارة الشاليهات والمستحقات
  • إضافة وتعديل بيانات الوحدات: رفع صور عالية الجودة، تحديد المميزات، المرافق، السعة، والموقع الجغرافي.
  • نظام التسعير المتدرج والخصومات: تحديد أسعار ديناميكية حسب مدة الإقامة (سعر الليلة، خصم أسبوعي، وخصم شهري خاص).
  • التحكم الفوري في حالة الإتاحة: تغيير حالة الشاليه بنقرة زر (متاح، محجوز، تحت الصيانة، أو محجوز من منصة خارجية).
  • تقويم حجوزات تفاعلي: استعراض التواريخ المشغولة والقادمة وبيانات النزلاء لكل وحدة.
  • المحفظة المالية والأرباح: متابعة صافي الأرباح المحققة بعد خصم العمولة، وطلب سحب المستحقات البنكية.
3. موقع وتجربة العميل (Airbnb Experience)
واجهة الحجز والاستكشاف
  • تجربة تصفح فاخرة شبيهة بـ Airbnb: عرض بانورامي للقرى والشاليهات وسكن الشركات بتصميم عصري وجذاب.
  • محرك بحث ذكي وفلاتر دقيقة: تصفية حسب التاريخ، عدد النزلاء، السعر، الإطلالة، والقرب من البحر.
  • نظام مقارنة الوحدات (Side-by-Side): مقارنة المواصفات والأسعار لاختيار أفضل شاليه.
  • حجز فوري ودفع آمن: سلة حجز سريعة، تأكيد إلكتروني، وإصدار الفاوتشر الفوري.
  • دعم كونسيرج 24/7 من Ragab Pay: محادثة مباشرة وواتساب للدعم والمساعدة طوال الإقامة.
  • خدمات VIP وباقات إضافية: إمكانية طلب شيف خاص، ليموزين، يخوت، وخدمات سياحية إضافية.
4. تطبيق الهاتف ونشره (iOS & Android)
App Store & Google Play
  • تطبيق جوال أصيل/هجين موحد: أداء عالي وسلس متوافق تماماً مع شاشات هواتف آيفون وأندرويد.
  • رفع التطبيق على Apple App Store: تجهيز حساب المطور، الشهادات، ومتابعة اعتماد أبل حتى النشر.
  • رفع التطبيق على Google Play Store: مطابقة معايير Google وتجهيز لقطات الشاشة ونشره رسمياً.
  • إشعارات Push فورية عبر Firebase: تنبيهات بتأكيد الحجز، الدفع، والعروض الحصرية.
  • استعراض الفاوتشر السريع: استعراض فاوتشر الحجز وتفاصيل الوصول أوفلاين بكل سلاسة.

الحزمة التقنية ومراحل التنفيذ (Tech Stack & Architecture)

Enterprise Scalability, Integrations & Phased Roadmap

SYSTEM ARCHITECTURE
المعمارية: Clean Architecture / Scalable
ثانياً: الحزمة التقنية المعتمدة للمنظومة (Enterprise Technology Stack)
.NET Web API (C#)
خوادم خلفية فائقة السرعة، بنية Clean Architecture، أمان عالي، ومطابقة للمعايير المؤسسية مع دعم التوثيق التلقائي لـ Swagger.
SQL Server Database
قاعدة بيانات علائقية متقدمة تدعم العمليات المالية المعقدة، الفهارس الذكية، والنسخ الاحتياطي التلقائي مع حفظ سلامة البيانات.
Angular 19 + Tailwind
واجهات مستخدم تفاعلية (SPA) سريعة الاستجابة للوحات الثلاث مع دعم كامل لاتجاه RTL العربي وتجاوب كامل مع مختلف الشاشات.
Firebase (FCM)
منظومة الإشعارات السحابية الفورية (Push Notifications) للنزلاء والملاك وإدارة المنصة في الوقت الفعلي مع سجل تنبيهات.
ثالثاً: قنوات الربط والتكامل المدمجة (Integrated Services)
SMS Integration
ربط بوابة الرسائل القصيرة لإرسال رموز التحقق (OTP)، تأكيد الحجز، وإشعارات العمليات المالية الفورية.
WhatsApp API
إرسال الفاوتشر وتفاصيل الوصول وموقع الشاليه التلقائي للنزيل، مع قناة تواصل مباشرة مع كونسيرج المنصة.
Email Integration
إرسال الفواتير الرسمية، إشعارات العقود المعتمدة للملاك، وملخص الحجوزات عبر خوادم SMTP / SendGrid.
Payment Gateways
ربط بوابات الدفع الإلكتروني (Paymob / Stripe) لدعم فيزا، ماستركارد، ميزة، المحافظ الإلكترونية، وأبل باي.
رابعاً: خطة مراحل التنفيذ (Project Roadmap) - مع عزل مرحلة الـ AI
المرحلة الأولى 6 أسابيع
البنية الخلفية واللوحات الثلاث
  • هندسة قاعدة بيانات SQL Server والـ APIs بـ .NET Core.
  • لوحة الإدارة العامة (KYC، مراجعة الوحدات، والعمولات المتغيرة).
  • بوابة المالك (إدارة الشاليهات والتسعير المتدرج والمستحقات).
  • موقع النزيل والعميل بتجربة Airbnb واستكشاف الوحدات.
المرحلة الثانية 4 أسابيع
الموبايل والمتاجر ومحركات الربط
  • تطوير تطبيق الهاتف الموحد لنظامي iOS و Android.
  • رفع واعتماد التطبيق رسمياً على Apple App Store و Google Play.
  • ربط بوابات الدفع الإلكتروني وإشعارات Firebase.
  • تكامل رسائل الـ SMS وتنبيهات WhatsApp و Email.
المرحلة 3 (مستقلة بالكامل) 3 أسابيع
نموذج ومحرك الذكاء الاصطناعي (AI)
  • تطوير مستشار الحجز الذكي التفاعلي (Conversational AI).
  • خوارزميات البحث الدلالي بالمعنى والمواصفات.
  • نموذج التوصيات والتسعير التكيفي لتعظيم أرباح الملاك.
  • تدريب النموذج واختبار دقته بعد استقرار التشغيل الفعلي.
ميزة عزل مرحلة الذكاء الاصطناعي (AI Phase Isolation): يتيح هذا العزل إطلاق وتشغيل المنظومة الفندقية وحجز الشاليهات وتحصيل الإيرادات في السوق فور انتهاء المرحلتين 1 و 2، ثم تدريب محرك الـ AI في المرحلة 3 اعتماداً على البيانات الحقيقية للوحدات وسلوك النزلاء دون تأخير الإطلاق التشغيلي.
